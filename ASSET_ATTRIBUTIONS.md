# Copper chess artwork

- images/chess-editorial.webp: original artwork generated for Jenga-Code using the built-in image generator. Brief: copper engraved Staunton knight, fine muted navy celestial compass circles, moon, restrained botanical branches and mountain detail, transparent background, no embedded text, intended as a narrow editorial margin beside the board.
- images/blitz.svg, rapid.svg, rapid-long.svg: original SVG line icons created for this interface; lightning, stopwatch and hourglass.
- Original supplied chess piece sprites are retained. See THIRD-PARTY-NOTICES.md and bundled licence files for existing dependencies.

Time-control naming references:
- https://www.chess.com/news/view/10-minute-chess-now-rapid-rated-bullet-ratings-increased
- https://support.chess.com/en/articles/8608949-how-do-live-tournaments-work-where-can-i-join-one

The app uses the generic categories Blitz and Rapid; the icons are original artwork.
